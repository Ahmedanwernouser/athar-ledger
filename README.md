# أثَر — سجلّ الاستشهادات المنطوقة

**العربية** · [English](README.en.md)

**ما الذي استشهد به المتحدث، وأين، وبأي لفظ؟**

**جرّبه الآن: https://athar-ledger.pages.dev** — مجاني، بلا تسجيل، بالعربية والإنجليزية.

> **English:** the full README is in [README.en.md](README.en.md).

المسار الرابع: أدوات المعرفة والتحقق.

## الفكرة

في المحاضرة الواحدة آيات وأحاديث تُقال من الحفظ. قد تتبدّل كلمة، أو يُنسب حديث إلى غير كتابه، أو يُذكر كلام مشهور على أنه حديث وليس في كتب الحديث. مراجعة ذلك يدويًّا تأخذ ساعات.

أثَر يأخذ المحاضرة ويعطيك **سجلًّا**: كل استشهاد، ولحظته في التسجيل، ونص مصدره، والفرق بينهما كلمةً كلمة. ثم يترك القرار للمراجِع.

## جرّبه في ثلاثين ثانية

1. افتح https://athar-ledger.pages.dev
2. الصق رابط محاضرة من يوتيوب، أو اضغط أحد أزرار «جرّب» تحت خانة الإدخال.
3. اقرأ «الملخص» ثم «السجل»، واضغط على أي وقت لتسمع الموضع في الفيديو.
4. نزّل النص بحواشيه ملف Word.
5. افتح «اسأل أثَر» واكتب: «هل هذا حديث: حب الوطن من الإيمان؟»

## ما الذي يفعله

| | |
|---|---|
| **ثلاث طرق للإدخال** | رابط يوتيوب (يُفرَّغ من الرابط مباشرة، بلا تحميل)، أو تسجيل صوتي، أو نص ملصوق. |
| **مطابقة كلمةً كلمة** | ما تبدّل، وما سقط، وما زِيد، والتقديم والتأخير. «مطابق حرفيًّا» لا تُعطى إلا إذا لم تتغيّر كلمة واحدة. |
| **يفهم أخطاء التفريغ** | يفرّق بين خطأ من التفريغ الآلي (ص/س، كلمتان ملتصقتان) وفرق حقيقي في اللفظ. |
| **فحص العزو** | إذا قال المتحدث «رواه البخاري» أو «في سورة البقرة»، يُقارَن ذلك بموضع النص فعلًا. |
| **درجة كل حديث** | كما سجّلها المحقّقون، باسم صاحب الحكم («صحيح — الألباني»، «في صحيح مسلم»، «اختُلف فيه»). منقولة من قاعدة البيانات، لا من الأداة. |
| **المشتهر على الألسنة** | كل نص يُبحث عنه أيضًا في خمسة كتب في الموضوعات والمشتهرات، ويُعرض كلام الكتاب نفسه عنه. |
| **كل حديث مرة واحدة** | مهما تكرّر أو قيل على مقاطع: نصّه كاملًا، وما قيل منه، ومصدره، وكل لحظة ذُكر فيها. |
| **اسأل أثَر** | عن المحاضرة («لخّصها»، «ماذا قال عن كذا؟ ومتى؟»)، أو عن أي آية وحديث بلا محاضرة: نصٌّ بمرجعه، من أخرجه ودرجته، هل هذا حديث، نصوص قريبة من موضوع، تفسير الجلالين، وعدد ورود كلمة في المصحف. |
| **المراجِع صاحب القرار** | يصحّح كلمة أخطأ فيها التفريغ، يضيف استشهادًا فات الأداة، يحكم على كل موضع، ويحفظ الجلسة ليكملها مراجِع آخر. |
| **تقرير جاهز** | ملف Word فيه نص المحاضرة وحاشية بمصدر كل آية وحديث ودرجته؛ ونص مفرَّغ (TXT) وترجمة مصاحبة بالأزمنة (SRT). |
| **عربي وإنجليزي** | الواجهة بلغتين، والمحاضرة الإنجليزية تُطابَق بترجمات منشورة تقود إلى النص العربي نفسه. |
| **مكتبة على طبقات** | القرآن وتسع مجموعات حديثية دائمًا، وحزم كتب عند الطلب: تفسير، فقه، سيرة، عقيدة. |

## الأمانة العلمية

هذه أداة تتعامل مع القرآن والحديث، فبُنيت على ثلاث قواعد:

- **لا تُفتي ولا تحكم على حديث.** سؤال الحكم الشرعي يُرفض بنص ثابت، والدرجات منقولة بأسماء أصحابها.
- **الوصف من عدّ الكلمات، لا من رأي نموذج.** «مطابق حرفيًّا» و«مطابق مع فروق» نتيجة مقارنة نصية حتمية بمصدر معروف.
- **النموذج اللغوي مقيَّد حيث يُستعمل.** في «اسأل أثَر» السؤال عن نص بعينه تجيب عنه الصفحة من البيانات مباشرة بلا نموذج. وحين يصوغ نموذجٌ جملة، تمرّ على مراجعة آلية تحذف أي درجة أو اقتباس ليس في البيانات، والنص والمصدر والدرجة تُعرض دائمًا في بطاقات من المصادر نفسها.

وما لا يجده يقول إنه لم يجده: «لم يُعثر عليه» تعني أنه ليس في الكتب المحمَّلة بهذا اللفظ، وليست حكمًا عليه.

## بالأرقام

- **المكتبة:** ٦٬٢٣٦ آية و٣٦٬٠٦٣ حديثًا من تسع مجموعات، و١٥ كتابًا في حزم؛ المجموع ١٦٣٬٠٤٨ مقطعًا (نحو ٩٫٦ مليون كلمة).
- **الاختبارات:** ٢٤٤ اختبارًا للمحرك والواجهة و٦٣٩ فحصًا للوسيط، تُشغَّل قبل كل نشر.
- **كشف الآيات:** ١٠٠٪ على نص نظيف و٩٥٪ حين تُصاب ٢٠٪ من الكلمات بأخطاء تفريغ، مقابل ٩١٫٧٪ و٨٣٫٣٪ لبحث تقريبي مرجعي.
- **كشف الحديث الحرفي:** ٩٩٫٤٪ ثم ٩٧٫٨٪.
- **الأخطاء الحرجة في المحاضرة:** ٠٫٧ مقابل ٨٫٠ للبحث المرجعي.
- **صرامة الوصف:** لم يُوصف أي اقتباس مغيَّر اللفظ بأنه «حرفي»، في كل مستويات الضجيج.
- **على نص بشري حقيقي** (تغريدات معيار QDetect، كشف الآيات): دقة ٩٧٫٤٪ واسترجاع ٨٢٫٢٪.
- **عشرون عبارة مشهورة ليست في كتب الحديث** («اطلبوا العلم ولو في الصين»…): لم تُطابَق واحدة منها بحديث.

أرقام الكشف والأخطاء والصرامة من محاضرات مركَّبة بأخطاء تفريغ محاكاة، وتُعاد كلها بأمر واحد: `npm run eval`. والطريقة والجداول الكاملة وما قيس على الخدمة المنشورة في `docs/DETAILS.md` و`docs/EVALUATION.md`.

## التشغيل محليًّا

المتطلبات: Node 20 أو أحدث، و Python 3. لا حاجة إلى `npm install`: المشروع بلا مكتبات خارجية.

```bash
git clone https://github.com/Ahmedanwernouser/athar-ledger && cd athar-ledger
npm run serve     # ثم افتح http://localhost:8788
npm test          # ٢٤٤ اختبارًا + ٦٣٩ فحصًا (نحو ٤ دقائق)
npm run eval      # يعيد إنتاج أرقام القياس (نحو ٤ دقائق)
```

لصق النص والأمثلة والبحث في المصادر وأسئلة «اسأل أثَر» عن نص بعينه تعمل محليًّا فورًا. رفع الصوت ورابط يوتيوب والصياغة بنموذج تحتاج نشر الوسيط `worker/`؛ الخطوات في `docs/SETUP_FREE_ACCOUNTS.md`.

## هيكل المستودع

```
public/     الموقع كاملًا: الواجهة، المحرّك (js/)، والمكتبة (data/)
worker/     الوسيط (Cloudflare Worker): التفريغ، يوتيوب، متجهات الجُمل، المدقّق والشات
tests/      اختبارات المحرّك والواجهة وأدوات «اسأل أثَر»
eval/       القياس: توليد المحاضرات، الأنظمة المرجعية، النتائج
tools/      بناء المكتبة والفهارس من المصادر
docs/       التفاصيل الكاملة، المصادر والتراخيص، القياس، الإعداد
Athr_audio&vido .ipynb   تجربة الفريق على Colab لتفريغ الصوت والفيديو (فصل الصوت، ثم التفريغ مقطعًا مقطعًا)
```

الفرع `main` هو المشروع، و`baseline-v0` (الوسم `v0-baseline`) نسخة البداية. بقية الفروع يكتبها GitHub Actions آليًّا (سجل النشر ونتائج تجارب الخدمة المنشورة) وليست كودًا.

## حدود معروفة

- المكتبة محدَّدة بما ذُكر أعلاه؛ ما ليس فيها يظهر «لم يُعثر عليه».
- الجودة تتبع جودة التفريغ، والاقتباسات الأقصر من ثماني كلمات تُكتشف أقل.
- الاقتباس بالمعنى والبحث بالموضوع اقتراحات تُعرض بهذا الوصف، لا مطابقات.
- السجل مسوّدة للمراجِع البشري، لا بديل عنه.
