## الفكرة

المحاضرات والخطب مليئة بآيات وأحاديث تُذكر من الحفظ. قد تتغير كلمة، أو يُنسب حديث إلى غير كتابه، أو تُذكر عبارة مشهورة على أنها حديث وهي ليست في كتب الحديث. ومراجعة ذلك يدويًا تستغرق ساعات.

**أثَر** يحلل المحاضرة ويعرض **سجلًا** كاملًا: كل استشهاد، ووقته في التسجيل، ونصه في المصدر، والفرق بين ما قيل وما في المصدر. ثم يترك القرار للمراجع.

## جرّبه في نصف دقيقة

1. افتح الموقع: https://athar-ledger.pages.dev
2. الصق رابط محاضرة من يوتيوب، أو اضغط أحد أزرار «جرّب» تحت خانة الإدخال.
3. اقرأ «الملخص» ثم «السجل»، واضغط على أي وقت لتسمع الموضع في الفيديو.
4. نزّل النص مع الحواشي في ملف Word.
5. افتح «اسأل أثَر» واكتب: هل هذا حديث: حب الوطن من الإيمان؟

## المميزات

| الميزة | الشرح |
|---|---|
| **ثلاث طرق للإدخال** | رابط يوتيوب دون تحميل، أو ملف صوتي، أو نص مكتوب. |
| **مقارنة كلمة بكلمة** | يُظهر الكلمات المتغيرة والمحذوفة والزائدة والتقديم والتأخير. ولا يُوصف الاقتباس بأنه «حرفي» إلا إذا لم تتغير فيه كلمة واحدة. |
| **التمييز بين خطأ التفريغ واختلاف اللفظ** | يفرّق بين خطأ التفريغ الآلي، مثل الخلط بين الصاد والسين، والاختلاف الحقيقي في اللفظ. |
| **التحقق من العزو** | إذا قال المتحدث «رواه البخاري» أو «في سورة البقرة» يتحقق من موضع النص فعلًا. |
| **درجة الحديث** | منقولة من قاعدة البيانات مع اسم المحدّث، مثل «صحيح — الألباني». الأداة لا تحكم من عندها. |
| **الأحاديث المشتهرة** | يبحث عن كل نص في خمسة كتب في الأحاديث المشتهرة والموضوعة، ويعرض كلام المؤلف كما هو. |
| **كل نص مرة واحدة** | مهما تكرر في المحاضرة: نصه الكامل، وما ذُكر منه، ومصدره، وكل وقت ذُكر فيه. |
| **اسأل أثَر** | عن المحاضرة: تلخيصها، وماذا قال المحاضر عن موضوع ومتى. أو عن أي آية وحديث: النص بمرجعه، والتخريج والدرجة، والتفسير، وعدد ورود كلمة في المصحف. |
| **اختيار النموذج** | نموذج الموقع يعمل مباشرة، ويمكن للمستخدم وضع مفتاحه الخاص ويبقى محفوظًا في متصفحه. |
| **القرار للمراجع** | يصحح أخطاء التفريغ، ويضيف ما لم يُكتشف، ويقيّم كل موضع، ويحفظ الجلسة ليكملها مراجع آخر. |
| **تقارير جاهزة** | ملف Word بالحواشي والمصادر، ونص مفرغ، وملف ترجمة مصاحبة بالتوقيت. |
| **عربي وإنجليزي** | الواجهة بلغتين، والمحاضرات الإنجليزية تُطابق بترجمات منشورة تقود إلى النص العربي. |
| **مكتبة على طبقات** | القرآن وتسع مجموعات حديثية دائمًا، وكتب التفسير والفقه والسيرة والعقيدة عند الطلب. |

## الأمانة العلمية

الأداة تتعامل مع القرآن والحديث، ولذلك بُنيت على ثلاث قواعد:

- **لا تفتي ولا تحكم على الأحاديث.** أسئلة الأحكام الشرعية تُرفض برد ثابت، والدرجات منقولة بأسماء أصحابها.
- **التصنيف ناتج عن مقارنة نصية.** «مطابق حرفيًا» و«مطابق مع فروق» نتيجة مقارنة مباشرة بمصدر معروف، وليست رأي نموذج لغوي.
- **النموذج اللغوي مقيّد.** الأسئلة عن نص محدد تُجاب من البيانات مباشرة دون نموذج. وعند استخدام النموذج تمر إجابته على مراجعة آلية تحذف أي درجة أو اقتباس غير موجود في البيانات.

وإذا لم يجد النص صرّح بذلك: «لم يُعثر عليه» تعني أنه غير موجود بهذا اللفظ في الكتب المتاحة، وليست حكمًا عليه.

## النتائج بالأرقام

| المقياس | النتيجة |
|---|---|
| حجم المكتبة | 6,236 آية، و36,063 حديثًا من تسع مجموعات، و15 كتابًا إضافيًا (163,048 مقطعًا) |
| الاختبارات | 244 اختبارًا للمحرك والواجهة، و639 فحصًا للخادم الوسيط، قبل كل نشر |
| كشف الآيات | 100% على النص السليم، و95% عند وجود أخطاء تفريغ في 20% من الكلمات (البحث المرجعي: 91.7% و83.3%) |
| كشف الحديث الحرفي | 99.4% على النص السليم، و97.8% عند 20% أخطاء |
| الأخطاء الحرجة لكل محاضرة | 0.7 مقابل 8.0 للبحث المرجعي |
| تصنيف «حرفي» خاطئ | صفر في كل المستويات |
| نصوص حقيقية (معيار QDetect) | دقة 97.4% واسترجاع 82.2% في كشف الآيات |
| عشرون عبارة مشهورة ليست حديثًا | لم تُطابق أي واحدة منها بحديث |

أرقام الكشف والأخطاء من محاضرات تجريبية أضيفت إليها أخطاء تفريغ، ويمكن إعادة القياس بأمر واحد. الجداول الكاملة في ملف docs/EVALUATION.md.

## التشغيل محليًا

المتطلبات: Node 20 أو أحدث، و Python 3. المشروع لا يحتاج إلى تثبيت أي مكتبات.

</div>

```bash
git clone https://github.com/Ahmedanwernouser/athar-ledger
cd athar-ledger
npm run serve     # then open http://localhost:8788
npm test          # 244 tests + 639 checks (about 4 minutes)
npm run eval      # reproduces the evaluation numbers (about 4 minutes)
```

النسخة المحلية تعمل بكل مميزات الموقع المنشور: التحليل والمقارنة داخل المتصفح، ورفع الملفات الصوتية وروابط يوتيوب والمحادثة عبر الخادم الوسيط للمشروع (يحتاج إلى اتصال بالإنترنت). ولنشر خادم وسيط خاص بك راجع ملف docs/SETUP_FREE_ACCOUNTS.md.

## حدود النظام

- المكتبة محددة بالمصادر المذكورة أعلاه، وما ليس فيها يظهر «لم يُعثر عليه».
- جودة النتائج تتبع جودة التفريغ، والاقتباسات الأقصر من ثماني كلمات تُكتشف بنسبة أقل.
- الاقتباس بالمعنى والبحث بالموضوع اقتراحات، وليست مطابقات مؤكدة.
- السجل مسودة للمراجع البشري، وليس بديلًا عنه.
